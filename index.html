Connector recovery, without exposing your data

This guide is for developers and integration maintainers troubleshooting OAuth renewal, permission scope, rate-limit, timeout and provider outage failures. The diagnosis runs locally in your browser.

What should I enter?

Only an HTTP status such as 401, 403, 429 or 503, or a normalized code such as TOKEN_EXPIRED or ETIMEDOUT.

What should I never paste?

Never paste a password, API key, OAuth token, complete server response, user message or personal identifier.

How can I verify or improve the tool?

Read the open-source documentation or send feedback in a GitHub issue. Do not include secrets or personal data.
